# spl2spark_server
the server components

== Installation ==
- Install Python (version >=2.7, 3.5 is recommended)
- Install Python requirements: pip install -r requirements.txt  (you might use pip3 for python 3)

== Run Flask ==

For a quick start, goto http://flask.pocoo.org/docs/0.12/quickstart/
The Flusk app file is: spl2spark_server.py.

The API is accessible at http://127.0.0.1:5000, for swagger documentation go to http://127.0.0.1:5000/doc/#/
